PASSER À ACCESS (.accdb)
  1. Access ▸ Créer une base vide ▸ enregistrer en .accdb
  2. Créer ▸ Création de requête ▸ fermer l'assistant ▸ bouton « Mode SQL »
  3. Coller UNE instruction du fichier sql/ à la fois puis Exécuter (!)
     (Access exécute une seule instruction par requête)
  4. Les CREATE VIEW deviennent des requêtes enregistrées : donnez-leur
     exactement le nom R1_MoyenneParEleve, R2_ElevesEnEchec, R3_NotesInformatique
  5. Les relations : onglet Outils de base de données ▸ Relations ▸ glisser
     IdEleve vers Note.IdEleve, cocher « Appliquer l'intégrité référentielle »
  6. Corriger ensuite normalement : la lecture .accdb exige
     pip install pyodbc + moteur ACE (Windows), ou mdbtools (Linux)

OBTENIR DES ESSAIS .ACCDB RÉELS
-------------------------------
Les copies sont fournies en .db (SQLite) car ce format se lit sur tout système.
Pour les convertir en vrais fichiers Access :

  VOTRE SOLUTION EN .ACCDB (binaire).
  accdb_sql/solution.accdb.sql : la solution complète prête à coller en
  Access (3 tables + données + 2 relations + 3 requêtes R1/R2/R3).
  Une fois collée et enregistrée dans Access, vous obtenez le VRAI
  solution.accdb corrigeable : python correcteur_access.py ... -s solution.accdb

  A) Sur Windows avec Access installé — conversion automatique
       pip install pyodbc msaccessdb
       python convertir_en_accdb.py . -o bd_accdb
     → bd_accdb/solution.accdb + 7 copies .accdb (tables, données,
       relations avec intégrité référentielle, requêtes R1/R2/R3)
     puis :
       python correcteur_access.py bd_accdb -s bd_accdb/solution.accdb --lang fr

  B) Sans moteur ACE — scripts SQL à coller (voie « A » ci-dessus impossible)
       python convertir_en_accdb.py . -o accdb_sql --sql-seulement
     → accdb_sql/*.accdb.sql (déjà générés dans ce dossier)
     Dans Access : Créer ▸ Création de requête ▸ fermer l'assistant ▸
     bouton « Mode SQL » ▸ coller UNE instruction ▸ Exécuter (!)
     Le SQL est déjà adapté au dialecte Jet : AUTOINCREMENT, TEXT(n), LONG,
     DOUBLE, DATETIME, dates entre #…#, INNER JOIN, alias AS, GROUP BY complet.

  modele_vide.accdb / solution.accdb : bases Access vides (fournies par
  msaccessdb) si vous voulez partir d'un fichier .accdb neuf sans ouvrir Access.
